# Phases 6–10 Implementation Plan (run in cascade)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take the MVP (phases 1–5) to the full product of CLAUDE.md §6–§9.

**Architecture:** unchanged. Every external service goes behind an interface with a development fake (§8.8): `DomainProvider` (Vercel), `EmailDomainProvider` (Resend), `DocumentExtractor` (Anthropic), `PaymentProvider` (Stripe, GoCardless), `InvoiceCompliance` (Verifactu). Pure logic first with unit tests, services with `can()` + `tenantDb()` + audit, thin actions and pages. One branch per phase, merged `--no-ff` into `main`; each phase ends with tests, lint, typecheck, seed, README and tech-debt updates.

**Spec:** `CLAUDE.md` §6.4, §6.10–§6.15, §7, §9.

## Phase 6 — White label
- [ ] `modules/branding/contrast.ts`: WCAG contrast ratio, automatic foreground, warnings (tests).
- [ ] Branding: favicon, sender name, contrast warnings on save.
- [ ] Custom domain: TXT verification (`_portal-verify.<domain>`), CNAME instructions, `DomainProvider` (Vercel API / fake) for SSL (tests with an injected DNS resolver).
- [ ] Sending domain: `EmailDomainProvider` (Resend / fake), SPF/DKIM/DMARC records and status; verified domain becomes the From address.
- [ ] Email templates: one registry for every system email, tenant overrides with preview, branded HTML wrapper.
- [ ] i18n: `lib/i18n` with `es` and empty `ca`, `gl`, `eu`, `en` falling back to Spanish.

## Phase 7 — AI extraction and accounting export
- [ ] `DocumentExtractor` interface, Anthropic vision implementation, deterministic fake; Zod-validated JSON, one corrective retry, `FAILED` fallback; token usage per tenant.
- [ ] Extraction job after the file is clean; period suggested from the invoice date; field-duplicate check after extraction; confidence in the inbox.
- [ ] 10 synthetic invoices in `fixtures/` + acceptance test (≥ 9 correct totals and dates).
- [ ] Export of a period to CSV and XLSX (own minimal writer) with configurable columns and decimal separator.

## Phase 8 — Billing
- [ ] Recurring fees, invoice drafting/issuing with gap-free numbering under a row lock (concurrency test), rectifying invoices, PDF with Spanish legal data.
- [ ] `InvoiceCompliance` (hash chain + QR payload), `PaymentProvider` (Stripe card, GoCardless SEPA) with fakes; webhooks with signature check and idempotency (tests).
- [ ] Monthly generation job, dunning at 3/10/20 days, `DELINQUENT` at 30, all configurable.

## Phase 9 — Security and GDPR operations
- [ ] TOTP 2FA with recovery codes, mandatory for staff; encrypted secrets; session list and revoke.
- [ ] Rate limiting (Redis) on auth, sign-up, uploads and webhooks; security headers and nonce-based CSP.
- [ ] DPA generation and recorded acceptance; client export + erasure with 30-day grace; tenant export (ZIP) and purge after 30 days; retention policy; support mode.

## Phase 10 — PWA, help, demo, polish
- [ ] Manifest, icons, installable; offline upload queue in IndexedDB; service worker shell cache.
- [ ] `/ayuda` from Markdown (8–10 articles); demo banner everywhere and nightly re-seed job; error reporting; performance and accessibility pass; final README and §9 checklist.
